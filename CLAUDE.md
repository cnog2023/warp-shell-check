# warp-research: instructions for every session

Read `RESUME.md` first: where the last session stopped, and what the next part needs that is not in the repository.

Read, in this order, before doing anything: `INDEX.md` (what we have and where), `PLAN.md` (what we
are doing and which step we are on), `CLAIMS.md` (what is under test and its status). Then the latest
file in `work/notes/`.

Rules:

1. A claim is quoted and located before it is tested. Summaries, including mine from earlier
   sessions, are hypotheses.
2. Every number in a document names the file and location it came from.
3. Every computation is reproducible from this folder with the commands in its README. Write the
   README with the code, not after.
4. Two implementations for anything that becomes a headline number: WarpFactory and warpax, or an
   analytic answer and one of them.
5. `sources/` and `repos/` are other people's work. Read, quote, cite; never edit, never commit.
6. Outward communication, repository creation, and anything in Carlos's name is his to send. Draft
   it, hand it over.
7. Neutral tone in everything that may be published. Both sides of the dispute are quoted the same
   way.
8. Python runs from `.venv` in this folder. Pin float64 in anything JAX touches.

Memory of how this folder came to be: a conversation in the HeimHero project on 26-27 September and
18 October 2026, starting from a question about WarpFactory and ending at the plan in `PLAN.md`.
